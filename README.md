# claude-prueba

Repositorio de prueba para aprender el flujo de trabajo con GitHub y Claude Code:
crear ramas, hacer commits y abrir pull requests.

## Flujo de trabajo

1. Crea una rama a partir de `main`:
   ```bash
   git checkout -b mi-rama
   ```
2. Haz tus cambios y confírmalos:
   ```bash
   git add .
   git commit -m "Describe el cambio"
   ```
3. Sube la rama y abre un pull request contra `main`:
   ```bash
   git push -u origin mi-rama
   ```
